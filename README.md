# 志愿者服务活动中心多媒体展示系统

一个功能完善的志愿者服务管理平台，支持多端协作，包含内容管理、活动管理、志愿者管理、多媒体发布等功能。

## 📋 项目简介

本系统采用前后端分离架构，为志愿者服务中心提供一站式数字化管理解决方案。系统支持四种角色（管理员、志愿者组织、志愿者、普通用户），实现内容发布、活动组织、志愿者招募、求助处理等核心业务流程。

## 🛠️ 技术栈

| 层级 | 技术 |
|-----|------|
| 后端框架 | Spring Boot 3.2 + MyBatis-Plus 3.5 |
| 安全认证 | Spring Security + JWT |
| 数据库 | MySQL 8.0 |
| 前端框架 | Vue 3 + TypeScript |
| UI 组件 | Element Plus |
| 构建工具 | Maven / Vite |

## ✨ 功能特性

### 🔐 管理员端 (`/login`)

- **仪表盘** - 系统数据统计概览、操作日志
- **用户管理** - 用户增删改查、角色分配、账号启用/禁用
- **志愿者审核** - 审核志愿者注册申请，自动启用账号
- **操作日志** - 系统操作记录查询
- **系统设置** - 系统参数配置

### 🏢 志愿者组织端 (`/org`)

- **工作台** - 组织数据统计、待办事项
- **内容管理** - 资讯内容发布、分类管理
- **媒体管理** - 图片/视频上传、播放列表管理
- **多媒体发布** - 布局设计、插播管理、终端管理
- **活动管理** - 活动发布、报名管理、签到码、仅限成员活动
- **志愿者管理** - 成员审核、组织成员列表
- **求助处理** - 处理用户求助请求

### 👤 志愿者端 (`/portal`)

- **首页** - 志愿者统计数据展示
- **活动报名** - 浏览活动、在线报名、取消报名
- **活动签到** - 签到码签到
- **资讯浏览** - 分类浏览资讯内容
- **媒体展示** - 图片/视频浏览
- **加入组织** - 申请加入志愿者组织、退出组织
- **个人中心** - 个人信息、我的报名、消息通知

### 👥 普通用户端 (`/user-portal`)

- **内容浏览** - 浏览公开资讯内容
- **媒体观看** - 观看公开图片/视频
- **发布求助** - 向志愿者组织发起求助
- **求助记录** - 查看求助处理进度

### 📺 终端播放 (`/screen`)

- **大屏播放** - 终端设备内容播放
- **心跳上报** - 终端在线状态监控

## 🚀 快速开始

### 环境要求

- JDK 17+
- Node.js 18+
- MySQL 8.0+
- Maven 3.8+

### 1. 数据库配置

```sql
CREATE DATABASE IF NOT EXISTS volunteer 
    DEFAULT CHARACTER SET utf8mb4 
    DEFAULT COLLATE utf8mb4_unicode_ci;
```

执行 `backend/src/main/resources/volunteer_complete.sql` 初始化表结构和数据。

### 2. 后端启动

```bash
cd backend
# 修改 application.yml 中的数据库配置
mvn spring-boot:run
```

后端地址：http://localhost:8080

### 3. 前端启动

```bash
cd frontend
npm install
npm run dev
```

前端地址：http://localhost:5173
