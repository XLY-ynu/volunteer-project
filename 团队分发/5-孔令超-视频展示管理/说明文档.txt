一、项目运行方式
================================================================================

1. 环境要求
-----------
   - Node.js 18.x 或更高版本
   - npm 9.x 或更高版本
   - 现代浏览器（Chrome、Firefox、Edge等）

2. 安装依赖
-----------
   打开命令行，进入 frontend 目录，执行：
   cd frontend
   npm install

3. 启动开发服务器
-----------------
   npm run dev
   
   启动后访问：http://localhost:5173

4. 构建生产版本
---------------
   npm run build
   
   构建产物位于 frontend/dist 目录

5. 后端服务
-----------
   本模块需要配合后端服务运行，后端服务地址配置在 vite.config.ts 中
   默认代理到 http://localhost:8080/api

6. 登录账号
-----------
   志愿者组织账号：org1 / org123
   志愿者账号：通过注册获取


二、需求分析
================================================================================

1. 模块概述
-----------
   视频展示管理模块是志愿者服务管理系统的媒体管理模块，面向志愿者组织管理员
   和志愿者用户。该模块包含两个子模块：
   (1) 志愿者组织端：视频展示管理（媒体资源库、播放列表）
   (2) 志愿者端：活动参与（登录、个人信息、参与记录）
   
   通过本模块，志愿者组织可以管理媒体资源和播放列表，志愿者可以参与活动并签到。

2. 用户角色
-----------
   目标用户：
   (1) 志愿者组织管理员
       - 负责上传和管理媒体资源
       - 负责创建和编辑播放列表
       - 负责发布内容到终端
   
   (2) 志愿者
       - 登录个人账号
       - 查看和编辑个人信息
       - 查看参与记录和服务时长
       - 进行活动签到

3. 功能需求
-----------

   3.1 志愿者组织端 - 媒体资源库
   -----------------------------
   功能描述：提供视频、图片资源的上传和存储功能
   
   具体功能：
   (1) 资源列表
       - 分页显示所有媒体资源
       - 显示缩略图、文件名、类型、大小、上传时间
       - 支持按类型筛选（视频/图片/音频）
       - 支持按名称搜索
   
   (2) 上传资源
       - 支持拖拽上传
       - 支持批量上传
       - 支持的视频格式：MP4、AVI、MOV、WMV
       - 支持的图片格式：JPG、PNG、GIF、BMP
       - 上传进度显示
       - 自动生成缩略图
   
   (3) 资源管理
       - 预览资源（图片查看、视频播放）
       - 下载资源
       - 删除资源
       - 修改资源名称
   
   (4) 资源信息
       - 显示文件详细信息
       - 显示视频时长
       - 显示图片尺寸

   3.2 志愿者组织端 - 播放列表
   ---------------------------
   功能描述：将新闻资讯内容与媒体视频进行混合编排，设置播放时长
   
   具体功能：
   (1) 播放列表管理
       - 显示所有播放列表
       - 显示列表名称、项目数量、总时长、创建时间
       - 创建新播放列表
       - 编辑播放列表
       - 删除播放列表
   
   (2) 列表内容编排
       - 添加媒体资源到列表
       - 添加新闻资讯到列表
       - 拖拽调整播放顺序
       - 设置每项播放时长
       - 设置过渡效果
   
   (3) 播放预览
       - 预览播放列表效果
       - 模拟终端播放
   
   (4) 发布到终端
       - 选择目标终端
       - 设置播放时间段
       - 发布播放列表

   3.3 志愿者端 - 账号登录
   -----------------------
   功能描述：志愿者登录和注册功能
   
   具体功能：
   (1) 登录功能
       - 手机号+密码登录
       - 记住登录状态
       - 忘记密码找回
   
   (2) 注册功能
       - 填写基本信息
       - 手机号验证
       - 设置密码

   3.4 志愿者端 - 个人信息
   -----------------------
   功能描述：查看和编辑个人资料
   
   具体功能：
   (1) 信息展示
       - 显示姓名、手机号、邮箱
       - 显示所属单位
       - 显示注册时间
       - 显示志愿者编号
   
   (2) 信息编辑
       - 修改姓名
       - 修改邮箱
       - 修改所属单位
       - 修改密码

   3.5 志愿者端 - 参与记录
   -----------------------
   功能描述：统计个人志愿服务时长和次数
   
   具体功能：
   (1) 统计数据
       - 总服务时长
       - 总参与次数
       - 本月服务时长
       - 本月参与次数
   
   (2) 活动记录
       - 显示参与的活动列表
       - 显示活动名称、时间、地点
       - 显示签到状态
       - 显示服务时长
   
   (3) 签到功能
       - 扫码签到
       - 输入签到码签到
       - 签到成功提示

4. 业务流程
-----------

   4.1 媒体发布流程
   ----------------
   上传媒体 -> 创建播放列表 -> 添加内容 -> 编排顺序 -> 发布到终端

   4.2 活动签到流程
   ----------------
   志愿者登录 -> 查看活动 -> 到达现场 -> 扫码/输入签到码 -> 签到成功

5. 非功能需求
-------------
   (1) 性能要求
       - 支持大文件上传（最大500MB）
       - 视频流畅播放
       - 列表拖拽流畅
   
   (2) 兼容性
       - 支持主流视频格式
       - 支持主流图片格式
   
   (3) 用户体验
       - 上传进度实时显示
       - 拖拽排序直观


三、详细设计
================================================================================

1. 系统架构设计
---------------
   本模块采用前后端分离架构：
   
   前端技术栈：
   - Vue 3 - 渐进式JavaScript框架
   - TypeScript - 类型安全的JavaScript超集
   - Element Plus - Vue 3 UI组件库
   - Pinia - Vue 3 状态管理
   - Vue Router - 路由管理
   - Axios - HTTP请求库
   - Vite - 构建工具
   - vuedraggable - 拖拽排序组件

2. 数据库设计
-------------

   2.1 媒体资源表（media）
   -----------------------
   字段名          类型            说明
   ----------------------------------------------------------------
   id              BIGINT          主键，自增
   filename        VARCHAR(255)    原始文件名
   filepath        VARCHAR(500)    存储路径
   file_type       VARCHAR(20)     文件类型（image/video/audio）
   file_size       BIGINT          文件大小（字节）
   mime_type       VARCHAR(100)    MIME类型
   thumbnail       VARCHAR(500)    缩略图路径
   duration        INT             时长（秒，视频/音频）
   width           INT             宽度（图片/视频）
   height          INT             高度（图片/视频）
   org_id          BIGINT          所属组织ID
   created_at      DATETIME        创建时间
   
   索引：
   - PRIMARY KEY (id)
   - KEY idx_org_id (org_id)
   - KEY idx_file_type (file_type)

   2.2 播放列表表（playlists）
   ---------------------------
   字段名          类型            说明
   ----------------------------------------------------------------
   id              BIGINT          主键，自增
   name            VARCHAR(100)    列表名称
   description     VARCHAR(500)    列表描述
   total_duration  INT             总时长（秒）
   item_count      INT             项目数量
   org_id          BIGINT          所属组织ID
   created_at      DATETIME        创建时间
   updated_at      DATETIME        更新时间
   
   索引：
   - PRIMARY KEY (id)
   - KEY idx_org_id (org_id)

   2.3 播放列表项表（playlist_items）
   ----------------------------------
   字段名          类型            说明
   ----------------------------------------------------------------
   id              BIGINT          主键，自增
   playlist_id     BIGINT          播放列表ID
   item_type       VARCHAR(20)     项目类型（media/content）
   item_id         BIGINT          关联ID（媒体ID或内容ID）
   duration        INT             播放时长（秒）
   sort_order      INT             排序序号
   transition      VARCHAR(20)     过渡效果
   created_at      DATETIME        创建时间
   
   索引：
   - PRIMARY KEY (id)
   - KEY idx_playlist_id (playlist_id)

   2.4 志愿者服务记录表（volunteer_service_records）
   -------------------------------------------------
   字段名          类型            说明
   ----------------------------------------------------------------
   id              BIGINT          主键，自增
   volunteer_id    BIGINT          志愿者ID
   activity_id     BIGINT          活动ID
   checkin_time    DATETIME        签到时间
   checkout_time   DATETIME        签退时间
   duration        INT             服务时长（分钟）
   status          VARCHAR(20)     状态（CHECKED_IN/COMPLETED）
   created_at      DATETIME        创建时间
   
   索引：
   - PRIMARY KEY (id)
   - KEY idx_volunteer_id (volunteer_id)
   - KEY idx_activity_id (activity_id)

3. 功能模块设计
---------------

   3.1 媒体管理模块
   ----------------
   
   (1) 组件结构
       Media.vue - 媒体管理主页面
       ├── 媒体列表（网格/列表视图）
       ├── 类型筛选区域
       ├── 上传区域（拖拽上传）
       ├── 媒体预览对话框
       └── 媒体详情对话框
   
   (2) API接口设计
       GET    /api/media                   获取媒体列表
       POST   /api/media/upload            上传媒体文件
       DELETE /api/media/:id               删除媒体
       GET    /api/media/:id/download      下载媒体

   3.2 播放列表模块
   ----------------
   
   (1) 组件结构
       Playlists.vue - 播放列表主页面
       ├── 播放列表表格
       ├── 创建列表对话框
       ├── 编辑列表对话框
       │   ├── 基本信息表单
       │   ├── 内容选择器
       │   └── 拖拽排序区域
       └── 预览对话框
   
   (2) API接口设计
       GET    /api/playlists               获取播放列表
       POST   /api/playlists               创建播放列表
       PUT    /api/playlists/:id           更新播放列表
       DELETE /api/playlists/:id           删除播放列表
       GET    /api/playlists/:id/items     获取列表项
       GET    /api/playlists/:id/preview   获取预览数据

   3.3 志愿者门户模块
   ------------------
   
   (1) 组件结构
       VolunteerPortal.vue - 志愿者门户主页面
       ├── 登录/注册区域
       ├── 个人信息卡片
       ├── 统计数据展示
       ├── 活动记录列表
       └── 签到功能区域
       
       VolunteerPublic.vue - 志愿者公开页面
       ├── 活动列表
       └── 签到入口
       
       Checkin.vue - 签到页面
       ├── 签到码输入
       └── 签到结果展示
   
   (2) API接口设计
       POST   /api/portal/auth/login       志愿者登录
       POST   /api/portal/auth/register    志愿者注册
       GET    /api/portal/me               获取个人信息
       PUT    /api/portal/me               更新个人信息
       GET    /api/portal/stats            获取统计数据
       GET    /api/portal/my-signups       获取报名记录
       POST   /api/portal/activities/signup 活动报名
       POST   /api/portal/checkin          活动签到

4. 前端路由设计
---------------
   路径              组件                  说明
   ----------------------------------------------------------------
   /login            Login.vue             登录页面
   /                 Layout.vue            主布局
   /media            Media.vue             媒体管理
   /playlists        Playlists.vue         播放列表
   /portal           VolunteerPortal.vue   志愿者门户
   /checkin          Checkin.vue           签到页面
   /volunteer-public VolunteerPublic.vue   志愿者公开页

5. 状态管理设计
---------------
   使用Pinia管理全局状态：
   
   userStore:
   - token: string      登录令牌
   - username: string   当前用户名
   - role: string       当前用户角色
   
   方法：
   - setToken()         设置令牌
   - logout()           退出登录

6. 文件上传设计
---------------
   (1) 上传流程
       选择文件 -> 校验格式和大小 -> 分片上传 -> 合并文件 -> 生成缩略图
   
   (2) 支持格式
       视频：MP4, AVI, MOV, WMV, MKV
       图片：JPG, JPEG, PNG, GIF, BMP, WEBP
       音频：MP3, WAV, AAC, FLAC
   
   (3) 大小限制
       视频：最大500MB
       图片：最大20MB
       音频：最大50MB
