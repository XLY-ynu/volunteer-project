一、项目运行方式
================================================================================

1. 环境要求
-----------
   - Node.js 18.x 或更高版本
   - npm 9.x 或更高版本
   - 现代浏览器（Chrome、Firefox、Edge等）

2. 安装依赖
-----------
   打开命令行，进入 frontend 目录，执行：
   cd frontend
   npm install

3. 启动开发服务器
-----------------
   npm run dev
   
   启动后访问：http://localhost:5173

4. 构建生产版本
---------------
   npm run build
   
   构建产物位于 frontend/dist 目录

5. 后端服务
-----------
   本模块需要配合后端服务运行，后端服务地址配置在 vite.config.ts 中
   默认代理到 http://localhost:8080/api

6. 登录账号
-----------
   志愿者组织账号：org1 / org123


二、需求分析
================================================================================

1. 模块概述
-----------
   活动管理模块是志愿者服务管理系统的核心业务模块，面向志愿者组织管理员。
   该模块包含两个子模块：
   (1) 活动管理：创建和管理志愿活动招募信息
   (2) 求助处理：接受和处理普通用户的求助请求
   
   通过本模块，志愿者组织可以发布活动、管理报名、统计签到，以及处理用户求助。

2. 用户角色
-----------
   目标用户：志愿者组织管理员
   用户特点：
   - 负责组织志愿活动
   - 负责管理活动报名
   - 负责统计活动数据
   - 负责处理用户求助

3. 功能需求
-----------

   3.1 活动发布功能
   ----------------
   功能描述：创建和发布志愿活动招募信息，支持编辑和删除操作
   
   具体功能：
   (1) 活动列表
       - 分页显示所有活动
       - 显示活动名称、时间、地点、状态
       - 显示报名人数/招募人数
       - 支持按状态筛选（招募中/进行中/已结束）
       - 支持按名称搜索
   
   (2) 创建活动
       - 活动名称（必填）
       - 活动描述（必填，支持富文本）
       - 活动地点（必填）
       - 活动时间（开始时间、结束时间）
       - 招募人数（必填）
       - 报名截止时间
       - 活动封面图片
       - 活动标签
       - 联系人信息
   
   (3) 编辑活动
       - 修改活动基本信息
       - 修改招募人数
       - 修改活动时间
       - 活动进行中不可修改关键信息
   
   (4) 删除活动
       - 删除未开始的活动
       - 已有报名的活动需确认
       - 进行中的活动不可删除

   3.2 报名管理功能
   ----------------
   功能描述：查看每个活动的报名人员名单，支持导出
   
   具体功能：
   (1) 报名列表
       - 显示报名人员信息
       - 显示姓名、手机号、报名时间
       - 显示签到状态
       - 支持按签到状态筛选
   
   (2) 报名审核
       - 审核通过报名
       - 拒绝报名（填写原因）
       - 批量审核操作
   
   (3) 名单导出
       - 导出为Excel格式
       - 可选择导出字段
       - 支持导出全部或筛选后数据

   3.3 签到统计功能
   ----------------
   功能描述：统计活动现场的签到打卡情况，生成参与率报表
   
   具体功能：
   (1) 签到统计
       - 显示签到人数/报名人数
       - 显示签到率
       - 显示签到时间分布
   
   (2) 签到详情
       - 显示每个人的签到时间
       - 显示签到方式（扫码/手动）
       - 显示未签到人员名单
   
   (3) 参与率报表
       - 生成活动参与率报表
       - 显示各时段签到人数
       - 支持导出报表

   3.4 待处理求助功能
   ------------------
   功能描述：查看普通用户提交的求助请求
   
   具体功能：
   (1) 求助列表
       - 显示所有求助请求
       - 显示求助标题、联系人、状态、提交时间
       - 支持按状态筛选（待处理/处理中/已完成）
       - 按时间倒序排列
   
   (2) 求助详情
       - 显示求助完整内容
       - 显示联系人信息
       - 显示地址信息

   3.5 求助回复功能
   ----------------
   功能描述：对求助进行回复处理，支持开始处理和直接完成
   
   具体功能：
   (1) 开始处理
       - 将状态改为"处理中"
       - 记录开始处理时间
       - 可添加处理备注
   
   (2) 回复求助
       - 填写回复内容
       - 可添加处理结果说明
   
   (3) 完成求助
       - 将状态改为"已完成"
       - 记录完成时间
       - 用户可查看回复

   3.6 处理记录功能
   ----------------
   功能描述：查看已处理和处理中的求助历史
   
   具体功能：
   (1) 历史记录
       - 显示所有已处理求助
       - 显示处理人、处理时间
       - 显示回复内容
   
   (2) 统计数据
       - 显示总求助数量
       - 显示平均处理时长
       - 显示各状态数量

4. 业务流程
-----------

   4.1 活动管理流程
   ----------------
   创建活动 -> 发布招募 -> 接受报名 -> 活动开始 -> 签到统计 -> 活动结束

   4.2 求助处理流程
   ----------------
   收到求助 -> 查看详情 -> 开始处理 -> 回复用户 -> 完成求助

5. 非功能需求
-------------
   (1) 数据统计
       - 实时更新报名数据
       - 实时更新签到数据
   
   (2) 通知提醒
       - 新求助提醒
       - 报名截止提醒
   
   (3) 数据导出
       - 支持Excel导出
       - 支持PDF导出


三、详细设计
================================================================================

1. 系统架构设计
---------------
   本模块采用前后端分离架构：
   
   前端技术栈：
   - Vue 3 - 渐进式JavaScript框架
   - TypeScript - 类型安全的JavaScript超集
   - Element Plus - Vue 3 UI组件库
   - Pinia - Vue 3 状态管理
   - Vue Router - 路由管理
   - Axios - HTTP请求库
   - Vite - 构建工具

2. 数据库设计
-------------

   2.1 活动表（activities）
   ------------------------
   字段名          类型            说明
   ----------------------------------------------------------------
   id              BIGINT          主键，自增
   title           VARCHAR(200)    活动名称
   description     TEXT            活动描述
   location        VARCHAR(255)    活动地点
   start_time      DATETIME        开始时间
   end_time        DATETIME        结束时间
   signup_deadline DATETIME        报名截止时间
   max_participants INT            最大参与人数
   current_participants INT        当前报名人数
   cover_image     VARCHAR(255)    封面图片URL
   contact_name    VARCHAR(50)     联系人姓名
   contact_phone   VARCHAR(20)     联系电话
   status          VARCHAR(20)     状态（RECRUITING/ONGOING/ENDED）
   org_id          BIGINT          所属组织ID
   created_at      DATETIME        创建时间
   updated_at      DATETIME        更新时间
   
   索引：
   - PRIMARY KEY (id)
   - KEY idx_org_id (org_id)
   - KEY idx_status (status)
   - KEY idx_start_time (start_time)

   2.2 活动报名表（activity_signups）
   ----------------------------------
   字段名          类型            说明
   ----------------------------------------------------------------
   id              BIGINT          主键，自增
   activity_id     BIGINT          活动ID
   volunteer_id    BIGINT          志愿者ID
   volunteer_name  VARCHAR(50)     志愿者姓名
   volunteer_phone VARCHAR(20)     志愿者电话
   status          VARCHAR(20)     状态（PENDING/APPROVED/REJECTED）
   checkin_status  VARCHAR(20)     签到状态（NOT_CHECKED/CHECKED_IN）
   checkin_time    DATETIME        签到时间
   reject_reason   VARCHAR(500)    拒绝原因
   created_at      DATETIME        报名时间
   
   索引：
   - PRIMARY KEY (id)
   - UNIQUE KEY uk_activity_volunteer (activity_id, volunteer_id)
   - KEY idx_activity_id (activity_id)
   - KEY idx_volunteer_id (volunteer_id)
   - KEY idx_status (status)

   2.3 求助请求表（help_requests）
   -------------------------------
   字段名          类型            说明
   ----------------------------------------------------------------
   id              BIGINT          主键，自增
   org_id          BIGINT          目标组织ID
   title           VARCHAR(200)    求助标题
   content         TEXT            求助内容
   contact_name    VARCHAR(50)     联系人姓名
   contact_phone   VARCHAR(20)     联系电话
   address         VARCHAR(255)    地址
   status          VARCHAR(20)     状态（PENDING/PROCESSING/COMPLETED）
   reply           TEXT            回复内容
   handler_id      BIGINT          处理人ID
   handler_name    VARCHAR(50)     处理人姓名
   started_at      DATETIME        开始处理时间
   completed_at    DATETIME        完成时间
   created_at      DATETIME        创建时间
   
   索引：
   - PRIMARY KEY (id)
   - KEY idx_org_id (org_id)
   - KEY idx_status (status)
   - KEY idx_created_at (created_at)

3. 功能模块设计
---------------

   3.1 活动管理模块
   ----------------
   
   (1) 组件结构
       OrgActivities.vue - 活动管理主页面
       ├── 活动列表表格
       ├── 状态筛选区域
       ├── 创建活动对话框
       │   ├── 基本信息表单
       │   ├── 时间设置
       │   └── 封面上传
       ├── 编辑活动对话框
       ├── 报名管理对话框
       │   ├── 报名列表
       │   ├── 审核操作
       │   └── 导出按钮
       └── 签到统计对话框
           ├── 统计数据
           ├── 签到详情
           └── 报表导出
   
   (2) API接口设计
       GET    /api/activities              获取活动列表
       POST   /api/activities              创建活动
       PUT    /api/activities/:id          更新活动
       DELETE /api/activities/:id          删除活动
       GET    /api/activities/:id/stats    获取活动统计
       GET    /api/activities/:id/signups  获取报名列表

   3.2 求助处理模块
   ----------------
   
   (1) 组件结构
       OrgHelpRequests.vue - 求助处理主页面
       ├── 求助列表表格
       ├── 状态筛选区域
       ├── 求助详情对话框
       │   ├── 求助信息展示
       │   └── 联系人信息
       └── 回复对话框
           ├── 回复内容输入
           └── 状态选择
   
   (2) API接口设计
       GET    /api/org/help-requests       获取求助列表
       POST   /api/org/help-requests/:id/reply  回复求助

4. 前端路由设计
---------------
   路径              组件                  说明
   ----------------------------------------------------------------
   /login            Login.vue             登录页面
   /                 Layout.vue            主布局
   /activities       OrgActivities.vue     活动管理
   /help-requests    OrgHelpRequests.vue   求助处理

5. 状态管理设计
---------------
   使用Pinia管理全局状态：
   
   userStore:
   - token: string      登录令牌（组织）
   - username: string   当前用户名
   - role: string       当前用户角色
   
   方法：
   - setToken()         设置令牌
   - logout()           退出登录

6. 界面设计
-----------
   (1) 活动管理页面
       - 顶部：状态筛选标签页
       - 中部：活动卡片/列表
       - 操作：创建、编辑、删除、查看报名、查看统计
   
   (2) 求助处理页面
       - 顶部：状态筛选
       - 中部：求助列表
       - 操作：查看详情、开始处理、回复、完成

7. 数据统计设计
---------------
   (1) 活动统计
       - 报名人数统计
       - 签到率统计
       - 时段分布统计
   
   (2) 求助统计
       - 求助数量统计
       - 处理时长统计
       - 状态分布统计
