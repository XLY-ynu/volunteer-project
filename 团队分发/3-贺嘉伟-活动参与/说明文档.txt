一、项目运行方式
================================================================================

1. 环境要求
-----------
   - Node.js 18.x 或更高版本
   - npm 9.x 或更高版本
   - 现代浏览器（Chrome、Firefox、Edge等）

2. 安装依赖
-----------
   打开命令行，进入 frontend 目录，执行：
   cd frontend
   npm install

3. 启动开发服务器
-----------------
   npm run dev
   
   启动后访问：http://localhost:5173

4. 构建生产版本
---------------
   npm run build
   
   构建产物位于 frontend/dist 目录

5. 后端服务
-----------
   本模块需要配合后端服务运行，后端服务地址配置在 vite.config.ts 中
   默认代理到 http://localhost:8080/api

6. 访问说明
-----------
   志愿者端功能需要登录后使用
   普通用户端部分功能无需登录


二、需求分析
================================================================================

1. 模块概述
-----------
   活动参与模块是志愿者服务管理系统的核心用户端模块，面向志愿者和普通用户。
   该模块包含两个子模块：
   (1) 志愿者端：加入志愿者组织功能
   (2) 普通用户端：成为志愿者功能
   
   通过本模块，普通用户可以申请成为志愿者，志愿者可以申请加入志愿者组织。

2. 用户角色
-----------
   目标用户：
   (1) 普通用户
       - 希望成为志愿者的社会人士
       - 需要填写个人信息申请注册
   
   (2) 志愿者
       - 已注册的志愿者用户
       - 希望加入志愿者组织参与活动

3. 功能需求
-----------

   3.1 志愿者端 - 加入志愿者组织
   -----------------------------
   功能描述：志愿者浏览平台上的志愿者组织，并申请加入
   
   具体功能：
   (1) 组织列表浏览
       - 显示所有志愿者组织
       - 显示组织名称、简介、成员数量
       - 显示组织Logo和联系方式
       - 支持按名称搜索组织
       - 支持按类型筛选组织
   
   (2) 组织详情查看
       - 显示组织完整介绍
       - 显示组织活动历史
       - 显示组织荣誉资质
       - 显示加入条件说明
   
   (3) 申请加入组织
       - 选择要加入的组织
       - 填写申请理由
       - 提交加入申请
       - 等待组织审核
   
   (4) 我的组织
       - 查看已加入的组织列表
       - 查看申请状态（待审核/已通过/已拒绝）
       - 查看拒绝原因（如有）
       - 退出已加入的组织

   3.2 普通用户端 - 成为志愿者
   ---------------------------
   功能描述：普通用户申请注册成为志愿者
   
   具体功能：
   (1) 申请注册
       - 填写基本信息表单
       - 阅读并同意志愿者协议
       - 提交注册申请
   
   (2) 填写资料
       必填信息：
       - 姓名（真实姓名）
       - 手机号（用于登录和联系）
       - 密码（账号密码）
       
       选填信息：
       - 邮箱（接收通知）
       - 所属单位（学校/公司）
       - 个人简介
       - 特长技能
   
   (3) 等待审核
       - 显示申请提交成功提示
       - 显示预计审核时间
       - 提供审核进度查询
   
   (4) 审核结果
       - 审核通过：可以登录志愿者端
       - 审核拒绝：显示拒绝原因，可重新申请

4. 业务流程
-----------

   4.1 成为志愿者流程
   ------------------
   普通用户 -> 填写注册信息 -> 提交申请 -> 等待审核 -> 审核通过 -> 成为志愿者
                                              |
                                              v
                                         审核拒绝 -> 查看原因 -> 重新申请

   4.2 加入组织流程
   ----------------
   志愿者 -> 浏览组织列表 -> 选择组织 -> 提交申请 -> 等待审核 -> 审核通过 -> 成为成员
                                              |
                                              v
                                         审核拒绝 -> 查看原因 -> 重新申请

5. 非功能需求
-------------
   (1) 数据验证
       - 手机号格式验证
       - 邮箱格式验证
       - 必填项检查
   
   (2) 用户体验
       - 表单自动保存
       - 友好的错误提示
       - 申请进度可视化
   
   (3) 安全性
       - 密码强度检查
       - 防止重复提交


三、详细设计
================================================================================

1. 系统架构设计
---------------
   本模块采用前后端分离架构：
   
   前端技术栈：
   - Vue 3 - 渐进式JavaScript框架
   - TypeScript - 类型安全的JavaScript超集
   - Element Plus - Vue 3 UI组件库
   - Pinia - Vue 3 状态管理
   - Vue Router - 路由管理
   - Axios - HTTP请求库
   - Vite - 构建工具

2. 数据库设计
-------------

   2.1 志愿者表（volunteers）
   --------------------------
   字段名          类型            说明
   ----------------------------------------------------------------
   id              BIGINT          主键，自增
   user_id         BIGINT          关联用户ID
   name            VARCHAR(50)     真实姓名
   phone           VARCHAR(20)     手机号
   email           VARCHAR(100)    邮箱
   organization    VARCHAR(100)    所属单位
   skills          VARCHAR(500)    特长技能
   bio             TEXT            个人简介
   status          VARCHAR(20)     状态（PENDING/APPROVED/REJECTED）
   reject_reason   VARCHAR(500)    拒绝原因
   created_at      DATETIME        创建时间
   approved_at     DATETIME        审核通过时间
   
   索引：
   - PRIMARY KEY (id)
   - UNIQUE KEY uk_user_id (user_id)
   - UNIQUE KEY uk_phone (phone)
   - KEY idx_status (status)

   2.2 志愿者组织表（volunteer_orgs）
   ----------------------------------
   字段名          类型            说明
   ----------------------------------------------------------------
   id              BIGINT          主键，自增
   name            VARCHAR(100)    组织名称
   code            VARCHAR(50)     组织编码
   description     TEXT            组织简介
   logo            VARCHAR(255)    Logo图片URL
   contact_name    VARCHAR(50)     联系人姓名
   contact_phone   VARCHAR(20)     联系电话
   contact_email   VARCHAR(100)    联系邮箱
   address         VARCHAR(255)    组织地址
   member_count    INT             成员数量
   status          VARCHAR(20)     状态（ACTIVE/INACTIVE）
   created_at      DATETIME        创建时间
   
   索引：
   - PRIMARY KEY (id)
   - UNIQUE KEY uk_code (code)
   - KEY idx_status (status)

   2.3 组织成员表（volunteer_org_members）
   ---------------------------------------
   字段名          类型            说明
   ----------------------------------------------------------------
   id              BIGINT          主键，自增
   org_id          BIGINT          组织ID
   volunteer_id    BIGINT          志愿者ID
   role            VARCHAR(20)     角色（MEMBER/ADMIN）
   status          VARCHAR(20)     状态（PENDING/APPROVED/REJECTED）
   apply_reason    VARCHAR(500)    申请理由
   reject_reason   VARCHAR(500)    拒绝原因
   applied_at      DATETIME        申请时间
   approved_at     DATETIME        审核时间
   
   索引：
   - PRIMARY KEY (id)
   - UNIQUE KEY uk_org_volunteer (org_id, volunteer_id)
   - KEY idx_org_id (org_id)
   - KEY idx_volunteer_id (volunteer_id)
   - KEY idx_status (status)

3. 功能模块设计
---------------

   3.1 志愿者门户模块
   ------------------
   
   (1) 组件结构
       VolunteerPortal.vue - 志愿者门户主页面
       ├── 登录/注册区域
       │   ├── 登录表单
       │   └── 注册表单
       ├── 个人信息区域
       │   ├── 基本信息展示
       │   └── 编辑个人资料
       ├── 组织列表区域
       │   ├── 组织卡片列表
       │   └── 申请加入对话框
       └── 我的组织区域
           ├── 已加入组织列表
           └── 申请状态列表
   
   (2) API接口设计
       POST   /api/portal/auth/login        志愿者登录
       POST   /api/portal/auth/register     志愿者注册
       GET    /api/portal/auth/check-phone  检查手机号是否已注册
       GET    /api/portal/me                获取个人信息
       PUT    /api/portal/me                更新个人信息
       GET    /api/portal/stats             获取个人统计数据

   3.2 普通用户门户模块
   --------------------
   
   (1) 组件结构
       UserPublicPortal.vue - 用户门户主页面
       ├── 成为志愿者入口
       │   ├── 功能介绍
       │   └── 立即申请按钮
       ├── 注册表单区域
       │   ├── 基本信息表单
       │   ├── 志愿者协议
       │   └── 提交按钮
       └── 申请状态查询
           ├── 手机号输入
           └── 状态显示
   
   (2) API接口设计
       GET    /api/public/orgs              获取组织列表
       POST   /api/public/org-applications  提交加入组织申请
       GET    /api/public/org-applications/my  查询我的申请
       POST   /api/public/volunteer/register   志愿者注册申请

   3.3 组织申请模块
   ----------------
   
   (1) 申请流程
       a. 志愿者浏览组织列表
       b. 点击"申请加入"按钮
       c. 填写申请理由
       d. 提交申请
       e. 等待组织管理员审核
   
   (2) 状态流转
       PENDING（待审核）-> APPROVED（已通过）
                       -> REJECTED（已拒绝）

4. 前端路由设计
---------------
   路径              组件                  说明
   ----------------------------------------------------------------
   /                 VolunteerPortal.vue   志愿者门户首页
   /portal           VolunteerPortal.vue   志愿者门户（别名）
   /user-portal      UserPublicPortal.vue  普通用户门户

5. 状态管理设计
---------------
   使用Pinia管理全局状态：
   
   userStore:
   - token: string      登录令牌
   - username: string   当前用户名
   - role: string       当前用户角色
   - profile: object    用户详细信息
   
   方法：
   - setToken()         设置令牌
   - setProfile()       设置用户信息
   - logout()           退出登录

6. 表单验证设计
---------------
   (1) 注册表单验证规则
       - 姓名：必填，2-20个字符
       - 手机号：必填，11位数字，格式验证
       - 密码：必填，6-20位，包含字母和数字
       - 邮箱：选填，格式验证
   
   (2) 申请表单验证规则
       - 申请理由：必填，10-500个字符

7. 界面设计
-----------
   (1) 志愿者门户
       - 左侧：个人信息卡片
       - 右侧：功能区域（组织列表/我的组织）
       - 底部：统计数据展示
   
   (2) 用户门户
       - 顶部：功能介绍横幅
       - 中部：注册表单
       - 底部：常见问题
