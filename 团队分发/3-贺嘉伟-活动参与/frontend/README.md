# 贺嘉伟 - 活动参与模块

## 运行说明

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev
```

## 前提条件

- 后端服务需要在 http://localhost:8080 运行
- 数据库需要正常连接
