一、项目运行方式
================================================================================

1. 环境要求
-----------
   - Node.js 18.x 或更高版本
   - npm 9.x 或更高版本
   - 现代浏览器（Chrome、Firefox、Edge等）

2. 安装依赖
-----------
   打开命令行，进入 frontend 目录，执行：
   cd frontend
   npm install

3. 启动开发服务器
-----------------
   npm run dev
   
   启动后访问：http://localhost:5173

4. 构建生产版本
---------------
   npm run build
   
   构建产物位于 frontend/dist 目录

5. 后端服务
-----------
   本模块需要配合后端服务运行，后端服务地址配置在 vite.config.ts 中
   默认代理到 http://localhost:8080/api

6. 访问说明
-----------
   本模块为公开访问模块，无需登录即可浏览内容
   志愿者端功能需要登录后使用


二、需求分析
================================================================================

1. 模块概述
-----------
   内容浏览模块是志愿者服务管理系统的前台展示模块，面向志愿者和普通用户。
   该模块提供了内容分类导航、内容详情查看、图片浏览、视频播放等功能，
   是用户了解志愿服务信息的主要入口。

2. 用户角色
-----------
   目标用户：
   (1) 普通用户（未登录访客）
       - 可以浏览公开内容
       - 可以查看活动信息
       - 可以观看宣传视频
   
   (2) 志愿者（已登录用户）
       - 拥有普通用户所有权限
       - 可以查看个人信息
       - 可以查看报名记录

3. 功能需求
-----------

   3.1 分类导航功能（普通用户端+志愿者端）
   ---------------------------------------
   功能描述：展示系统的六大主菜单分类入口，方便用户快速定位所需内容
   
   具体功能：
   (1) 分类展示
       - 显示一级分类列表
       - 每个分类显示图标和名称
       - 支持点击进入子分类
   
   (2) 分类导航
       - 面包屑导航显示当前位置
       - 支持返回上级分类
       - 显示当前分类下的内容数量
   
   六大主菜单分类：
   - 志愿服务动态
   - 志愿者风采
   - 活动招募
   - 政策法规
   - 培训学习
   - 关于我们

   3.2 内容详情功能（普通用户端+志愿者端）
   ---------------------------------------
   功能描述：查看具体内容的详细信息
   
   具体功能：
   (1) 内容列表
       - 分页显示内容列表
       - 显示标题、摘要、发布时间
       - 显示缩略图（如有）
       - 支持关键词搜索
   
   (2) 内容详情页
       - 显示完整标题
       - 显示发布时间和来源
       - 显示正文内容（支持富文本）
       - 显示相关图片
       - 显示相关视频（如有）
   
   (3) 推荐内容
       - 显示相关推荐内容
       - 显示热门内容排行

   3.3 图片浏览功能（普通用户端+志愿者端）
   ---------------------------------------
   功能描述：查看管理员发布的图片资源
   
   具体功能：
   (1) 图片列表
       - 网格布局展示图片
       - 显示图片缩略图
       - 显示图片标题
   
   (2) 图片预览
       - 点击放大查看原图
       - 支持图片轮播
       - 支持缩放和拖拽
   
   (3) 图片分类
       - 按分类筛选图片
       - 按时间排序

   3.4 视频播放功能（普通用户端+志愿者端）
   ---------------------------------------
   功能描述：观看宣传视频，支持全屏播放
   
   具体功能：
   (1) 视频列表
       - 显示视频封面
       - 显示视频标题和时长
       - 显示播放次数
   
   (2) 视频播放
       - 支持播放/暂停控制
       - 支持进度条拖拽
       - 支持音量调节
       - 支持全屏播放
       - 支持倍速播放
   
   (3) 视频推荐
       - 播放结束推荐相关视频

   3.5 志愿者端内容浏览
   --------------------
   功能描述：志愿者登录后的专属内容浏览功能
   
   具体功能：
   (1) 个人中心入口
       - 显示登录状态
       - 快速进入个人中心
   
   (2) 活动浏览
       - 查看可报名活动
       - 查看已报名活动状态

4. 非功能需求
-------------
   (1) 响应式设计
       - 适配PC端和移动端
       - 图片自适应显示
   
   (2) 性能优化
       - 图片懒加载
       - 内容分页加载
       - 视频预加载
   
   (3) 用户体验
       - 加载状态提示
       - 空数据友好提示
       - 流畅的动画效果


三、详细设计
================================================================================

1. 系统架构设计
---------------
   本模块采用前后端分离架构：
   
   前端技术栈：
   - Vue 3 - 渐进式JavaScript框架
   - TypeScript - 类型安全的JavaScript超集
   - Element Plus - Vue 3 UI组件库
   - Pinia - Vue 3 状态管理
   - Vue Router - 路由管理
   - Axios - HTTP请求库
   - Vite - 构建工具

2. 数据库设计
-------------

   2.1 分类表（categories）
   ------------------------
   字段名          类型            说明
   ----------------------------------------------------------------
   id              BIGINT          主键，自增
   name            VARCHAR(100)    分类名称
   code            VARCHAR(50)     分类编码
   parent_id       BIGINT          父分类ID（0表示顶级）
   icon            VARCHAR(100)    分类图标
   sort_order      INT             排序序号
   created_at      DATETIME        创建时间
   
   索引：
   - PRIMARY KEY (id)
   - KEY idx_parent_id (parent_id)
   - KEY idx_code (code)

   2.2 内容表（contents）
   ----------------------
   字段名          类型            说明
   ----------------------------------------------------------------
   id              BIGINT          主键，自增
   title           VARCHAR(200)    标题
   summary         VARCHAR(500)    摘要
   content         LONGTEXT        正文内容（HTML）
   category_id     BIGINT          所属分类ID
   cover_image     VARCHAR(255)    封面图片URL
   author          VARCHAR(50)     作者
   source          VARCHAR(100)    来源
   published       TINYINT(1)      是否发布
   headline        TINYINT(1)      是否头条
   recommended     TINYINT(1)      是否推荐
   recommend_weight INT            推荐权重
   sort_order      INT             排序序号
   view_count      INT             浏览次数
   created_at      DATETIME        创建时间
   updated_at      DATETIME        更新时间
   
   索引：
   - PRIMARY KEY (id)
   - KEY idx_category_id (category_id)
   - KEY idx_published (published)
   - KEY idx_created_at (created_at)

   2.3 媒体资源表（media）
   -----------------------
   字段名          类型            说明
   ----------------------------------------------------------------
   id              BIGINT          主键，自增
   filename        VARCHAR(255)    原始文件名
   filepath        VARCHAR(500)    存储路径
   file_type       VARCHAR(20)     文件类型（image/video/audio）
   file_size       BIGINT          文件大小（字节）
   mime_type       VARCHAR(100)    MIME类型
   thumbnail       VARCHAR(500)    缩略图路径
   duration        INT             时长（秒，视频/音频）
   width           INT             宽度（图片/视频）
   height          INT             高度（图片/视频）
   created_at      DATETIME        创建时间
   
   索引：
   - PRIMARY KEY (id)
   - KEY idx_file_type (file_type)
   - KEY idx_created_at (created_at)

3. 功能模块设计
---------------

   3.1 普通用户门户模块
   --------------------
   
   (1) 组件结构
       UserPublicPortal.vue - 用户门户主页面
       ├── 顶部导航栏
       ├── 分类导航区域
       ├── 推荐内容轮播
       ├── 内容列表区域
       └── 底部信息栏
   
   (2) 页面布局
       - 顶部：Logo + 搜索框 + 登录入口
       - 中部：分类导航 + 内容展示
       - 底部：版权信息 + 联系方式

   3.2 内容展示模块
   ----------------
   
   (1) 组件结构
       PublicContent.vue - 内容列表页面
       ├── 分类面包屑
       ├── 筛选排序区域
       ├── 内容卡片列表
       └── 分页组件
   
   (2) API接口设计
       GET    /api/public/categories        获取分类列表
       GET    /api/public/content           获取内容列表（分页）
       GET    /api/public/content/:id       获取内容详情
       GET    /api/public/recommendations   获取推荐内容

   3.3 媒体浏览模块
   ----------------
   
   (1) 图片浏览
       - 使用Element Plus的Image组件
       - 支持预览和缩放
       - 懒加载优化性能
   
   (2) 视频播放
       - 使用HTML5 Video标签
       - 自定义播放控制条
       - 支持全屏和倍速

   3.4 志愿者门户模块
   ------------------
   
   (1) 组件结构
       VolunteerPortal.vue - 志愿者门户页面
       ├── 登录/注册区域
       ├── 个人信息展示
       ├── 活动列表
       └── 报名记录
   
   (2) API接口设计
       POST   /api/portal/auth/login       志愿者登录
       POST   /api/portal/auth/register    志愿者注册
       GET    /api/portal/me               获取个人信息
       GET    /api/portal/my-signups       获取报名记录

4. 前端路由设计
---------------
   路径              组件                  说明
   ----------------------------------------------------------------
   /                 UserPublicPortal.vue  用户门户首页
   /user-portal      UserPublicPortal.vue  用户门户（别名）
   /public-content   PublicContent.vue     内容列表页
   /public-activities PublicActivities.vue 活动列表页
   /portal           VolunteerPortal.vue   志愿者门户

5. 状态管理设计
---------------
   使用Pinia管理全局状态：
   
   userStore:
   - token: string      登录令牌（志愿者）
   - username: string   当前用户名
   - role: string       当前用户角色
   
   方法：
   - setToken()         设置令牌
   - logout()           退出登录

6. 界面设计
-----------
   (1) 设计风格
       - 简洁清新的视觉风格
       - 以蓝色和绿色为主色调
       - 大量留白，突出内容
   
   (2) 响应式布局
       - PC端：三栏布局
       - 平板：两栏布局
       - 手机：单栏布局
   
   (3) 交互设计
       - 卡片悬停效果
       - 平滑滚动
       - 加载动画
