# 张昊然 - 内容浏览模块

## 运行说明

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev
```

## 前提条件

- 后端服务需要在 http://localhost:8080 运行
- 数据库需要正常连接

## 测试账号

- 用户名: testuser
- 密码: admin123

## 功能模块

- 用户门户 (/user-portal) - 内容浏览、媒体观看
- 公开内容 (/public-content)
- 公开活动 (/public-activities)

## 端口

- 开发服务器运行在 http://localhost:5179
