一、项目运行方式
================================================================================

1. 环境要求
-----------
   - Node.js 18.x 或更高版本
   - npm 9.x 或更高版本
   - 现代浏览器（Chrome、Firefox、Edge等）

2. 安装依赖
-----------
   打开命令行，进入 frontend 目录，执行：
   cd frontend
   npm install

3. 启动开发服务器
-----------------
   npm run dev
   
   启动后访问：http://localhost:5173

4. 构建生产版本
---------------
   npm run build
   
   构建产物位于 frontend/dist 目录

5. 后端服务
-----------
   本模块需要配合后端服务运行，后端服务地址配置在 vite.config.ts 中
   默认代理到 http://localhost:8080/api

6. 登录账号
-----------
   志愿者组织账号：org1 / org123


二、需求分析
================================================================================

1. 模块概述
-----------
   内容展示管理模块是志愿者服务管理系统的内容管理模块，面向志愿者组织管理员。
   该模块包含两个子模块：
   (1) 内容展示管理：分类管理和内容管理
   (2) 志愿者管理：审核和管理组织成员
   
   通过本模块，志愿者组织可以管理系统的分类结构、发布新闻资讯，以及管理志愿者成员。

2. 用户角色
-----------
   目标用户：志愿者组织管理员
   用户特点：
   - 负责内容分类管理
   - 负责新闻资讯发布
   - 负责志愿者审核
   - 负责成员管理

3. 功能需求
-----------

   3.1 分类管理功能
   ----------------
   功能描述：管理系统的六大主菜单分类结构
   
   具体功能：
   (1) 分类列表
       - 树形结构展示分类
       - 显示分类名称、编码、排序
       - 显示子分类数量
       - 显示关联内容数量
   
   (2) 创建分类
       - 分类名称（必填）
       - 分类编码（必填，唯一）
       - 父级分类（选填，不选则为顶级）
       - 排序序号
       - 分类图标
   
   (3) 编辑分类
       - 修改分类名称
       - 修改排序序号
       - 修改分类图标
       - 不可修改分类编码
   
   (4) 删除分类
       - 删除空分类
       - 有子分类的不可删除
       - 有关联内容的不可删除
   
   六大主菜单分类：
   - 志愿服务动态（news）
   - 志愿者风采（volunteer-style）
   - 活动招募（recruitment）
   - 政策法规（policy）
   - 培训学习（training）
   - 关于我们（about）

   3.2 内容管理功能
   ----------------
   功能描述：发布和编辑新闻资讯内容
   
   具体功能：
   (1) 内容列表
       - 分页显示所有内容
       - 显示标题、分类、状态、发布时间
       - 支持按分类筛选
       - 支持按状态筛选（草稿/已发布）
       - 支持按标题搜索
   
   (2) 创建内容
       - 内容标题（必填）
       - 内容摘要（选填）
       - 正文内容（必填，富文本编辑器）
       - 所属分类（必填）
       - 封面图片（选填）
       - 作者（选填）
       - 来源（选填）
       - 是否发布
       - 是否头条
       - 是否推荐
   
   (3) 编辑内容
       - 修改所有内容字段
       - 修改发布状态
       - 修改推荐状态
   
   (4) 删除内容
       - 删除指定内容
       - 删除前需确认
   
   (5) 内容排序
       - 拖拽调整内容顺序
       - 设置推荐权重

   3.3 志愿者管理 - 待审核列表
   ---------------------------
   功能描述：查看志愿者加入组织的申请
   
   具体功能：
   (1) 申请列表
       - 显示所有待审核申请
       - 显示申请人姓名、手机号、申请时间
       - 显示申请理由
       - 按申请时间倒序排列
   
   (2) 申请详情
       - 显示申请人完整信息
       - 显示申请理由
       - 显示申请人历史记录

   3.4 志愿者管理 - 审核操作
   -------------------------
   功能描述：支持审核通过或拒绝操作
   
   具体功能：
   (1) 审核通过
       - 将申请状态改为已通过
       - 将申请人加入组织成员
       - 发送通知给申请人
   
   (2) 审核拒绝
       - 将申请状态改为已拒绝
       - 填写拒绝原因（必填）
       - 发送通知给申请人
   
   (3) 批量审核
       - 批量通过多个申请
       - 批量拒绝多个申请

   3.5 志愿者管理 - 成员列表
   -------------------------
   功能描述：查看已通过审核的组织成员
   
   具体功能：
   (1) 成员列表
       - 显示所有组织成员
       - 显示姓名、手机号、加入时间
       - 显示服务时长统计
       - 支持按姓名搜索
   
   (2) 成员详情
       - 显示成员完整信息
       - 显示参与活动记录
       - 显示服务时长明细
   
   (3) 成员管理
       - 设置成员角色（普通成员/管理员）
       - 移除成员

4. 业务流程
-----------

   4.1 内容发布流程
   ----------------
   创建内容 -> 编辑正文 -> 设置分类 -> 上传封面 -> 发布内容

   4.2 志愿者审核流程
   ------------------
   收到申请 -> 查看详情 -> 审核通过/拒绝 -> 通知申请人

5. 非功能需求
-------------
   (1) 富文本编辑
       - 支持图片插入
       - 支持视频插入
       - 支持表格
   
   (2) 内容预览
       - 发布前预览效果
       - 模拟前台展示
   
   (3) 批量操作
       - 批量删除内容
       - 批量审核申请


三、详细设计
================================================================================

1. 系统架构设计
---------------
   本模块采用前后端分离架构：
   
   前端技术栈：
   - Vue 3 - 渐进式JavaScript框架
   - TypeScript - 类型安全的JavaScript超集
   - Element Plus - Vue 3 UI组件库
   - Pinia - Vue 3 状态管理
   - Vue Router - 路由管理
   - Axios - HTTP请求库
   - Vite - 构建工具

2. 数据库设计
-------------

   2.1 分类表（categories）
   ------------------------
   字段名          类型            说明
   ----------------------------------------------------------------
   id              BIGINT          主键，自增
   name            VARCHAR(100)    分类名称
   code            VARCHAR(50)     分类编码（唯一）
   parent_id       BIGINT          父分类ID（0表示顶级）
   icon            VARCHAR(100)    分类图标
   sort_order      INT             排序序号
   org_id          BIGINT          所属组织ID（0表示系统分类）
   created_at      DATETIME        创建时间
   
   索引：
   - PRIMARY KEY (id)
   - UNIQUE KEY uk_code (code)
   - KEY idx_parent_id (parent_id)
   - KEY idx_org_id (org_id)

   2.2 内容表（contents）
   ----------------------
   字段名          类型            说明
   ----------------------------------------------------------------
   id              BIGINT          主键，自增
   title           VARCHAR(200)    标题
   summary         VARCHAR(500)    摘要
   content         LONGTEXT        正文内容（HTML）
   category_id     BIGINT          所属分类ID
   cover_image     VARCHAR(255)    封面图片URL
   author          VARCHAR(50)     作者
   source          VARCHAR(100)    来源
   published       TINYINT(1)      是否发布（0-草稿，1-已发布）
   headline        TINYINT(1)      是否头条
   recommended     TINYINT(1)      是否推荐
   recommend_weight INT            推荐权重
   sort_order      INT             排序序号
   view_count      INT             浏览次数
   org_id          BIGINT          所属组织ID
   created_at      DATETIME        创建时间
   updated_at      DATETIME        更新时间
   
   索引：
   - PRIMARY KEY (id)
   - KEY idx_category_id (category_id)
   - KEY idx_org_id (org_id)
   - KEY idx_published (published)
   - KEY idx_created_at (created_at)

   2.3 组织成员表（volunteer_org_members）
   ---------------------------------------
   字段名          类型            说明
   ----------------------------------------------------------------
   id              BIGINT          主键，自增
   org_id          BIGINT          组织ID
   volunteer_id    BIGINT          志愿者ID
   role            VARCHAR(20)     角色（MEMBER/ADMIN）
   status          VARCHAR(20)     状态（PENDING/APPROVED/REJECTED）
   apply_reason    VARCHAR(500)    申请理由
   reject_reason   VARCHAR(500)    拒绝原因
   applied_at      DATETIME        申请时间
   approved_at     DATETIME        审核时间
   approved_by     BIGINT          审核人ID
   
   索引：
   - PRIMARY KEY (id)
   - UNIQUE KEY uk_org_volunteer (org_id, volunteer_id)
   - KEY idx_org_id (org_id)
   - KEY idx_status (status)

3. 功能模块设计
---------------

   3.1 分类管理模块
   ----------------
   
   (1) 组件结构
       Categories.vue - 分类管理主页面
       ├── 分类树形列表
       ├── 创建分类对话框
       │   ├── 基本信息表单
       │   └── 父级选择器
       └── 编辑分类对话框
   
   (2) API接口设计
       GET    /api/categories              获取分类列表
       POST   /api/categories              创建分类
       PUT    /api/categories/:id          更新分类
       DELETE /api/categories/:id          删除分类

   3.2 内容管理模块
   ----------------
   
   (1) 组件结构
       Content.vue - 内容管理主页面
       ├── 内容列表表格
       ├── 分类筛选区域
       ├── 创建内容对话框
       │   ├── 基本信息表单
       │   ├── 富文本编辑器
       │   └── 封面上传
       ├── 编辑内容对话框
       └── 内容预览对话框
   
   (2) API接口设计
       GET    /api/content                 获取内容列表
       POST   /api/content                 创建内容
       PUT    /api/content/:id             更新内容
       DELETE /api/content/:id             删除内容
       GET    /api/content/:id             获取内容详情

   3.3 志愿者管理模块
   ------------------
   
   (1) 组件结构
       OrgVolunteers.vue - 志愿者管理主页面
       ├── 状态标签页（待审核/已通过/已拒绝）
       ├── 成员列表表格
       ├── 审核对话框
       │   ├── 申请人信息
       │   ├── 通过按钮
       │   └── 拒绝表单
       └── 成员详情对话框
   
   (2) API接口设计
       GET    /api/org/volunteers          获取志愿者列表
       POST   /api/org/volunteers/:id/audit 审核志愿者

   3.4 仪表盘模块
   --------------
   
   (1) 组件结构
       OrgDashboard.vue - 组织仪表盘
       ├── 统计卡片区域
       │   ├── 成员数量
       │   ├── 待审核数量
       │   ├── 内容数量
       │   └── 活动数量
       └── 快捷操作区域
   
   (2) API接口设计
       GET    /api/org/dashboard           获取仪表盘数据

4. 前端路由设计
---------------
   路径              组件                  说明
   ----------------------------------------------------------------
   /login            Login.vue             登录页面
   /                 Layout.vue            主布局
   /dashboard        OrgDashboard.vue      组织仪表盘
   /categories       Categories.vue        分类管理
   /content          Content.vue           内容管理
   /volunteers       OrgVolunteers.vue     志愿者管理

5. 状态管理设计
---------------
   使用Pinia管理全局状态：
   
   userStore:
   - token: string      登录令牌（组织）
   - username: string   当前用户名
   - role: string       当前用户角色
   
   方法：
   - setToken()         设置令牌
   - logout()           退出登录

6. 富文本编辑器设计
-------------------
   (1) 功能支持
       - 文字格式（加粗、斜体、下划线）
       - 段落格式（标题、列表、引用）
       - 插入图片（上传/URL）
       - 插入视频（上传/URL）
       - 插入表格
       - 插入链接
   
   (2) 图片处理
       - 自动压缩大图
       - 支持拖拽上传
       - 支持粘贴上传

7. 界面设计
-----------
   (1) 分类管理页面
       - 左侧：分类树形结构
       - 右侧：分类详情和操作
   
   (2) 内容管理页面
       - 顶部：分类筛选和搜索
       - 中部：内容列表
       - 操作：创建、编辑、删除、预览
   
   (3) 志愿者管理页面
       - 顶部：状态标签页
       - 中部：成员列表
       - 操作：审核、查看详情
