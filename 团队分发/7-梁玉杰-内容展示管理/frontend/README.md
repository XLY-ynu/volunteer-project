# 梁玉杰 - 内容展示管理模块

## 运行说明

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev
```

## 前提条件

- 后端服务需要在 http://localhost:8080 运行
- 数据库需要正常连接

## 测试账号

- 用户名: org1
- 密码: admin123

## 功能模块

- 分类管理 (/categories)
- 内容管理 (/content)
- 志愿者管理 (/volunteers)
- 仪表盘 (/dashboard)

## 端口

- 开发服务器运行在 http://localhost:5177
