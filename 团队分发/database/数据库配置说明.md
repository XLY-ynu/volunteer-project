# 数据库配置说明

## 一、环境要求

- MySQL 8.0+
- 字符集：utf8mb4

## 二、快速初始化（推荐）

### 方式1：命令行执行（最简单）

```bash
# Windows CMD
mysql -u root -p < volunteer_complete.sql

# 或者指定完整路径
mysql -u root -p < "团队分发/database/volunteer_complete.sql"
```

### 方式2：MySQL Workbench

1. 打开 MySQL Workbench
2. 连接到本地 MySQL 服务器
3. 菜单：File → Open SQL Script
4. 选择 `volunteer_complete.sql` 文件
5. 点击执行按钮（闪电图标）

### 方式3：Navicat / DBeaver

1. 连接到 MySQL 服务器
2. 右键 → 运行 SQL 文件
3. 选择 `volunteer_complete.sql`
4. 执行

## 三、验证数据库

执行以下 SQL 验证数据是否正确导入：

```sql
USE volunteer;

-- 检查表数量（应该有 30+ 张表）
SELECT COUNT(*) AS table_count FROM information_schema.tables 
WHERE table_schema = 'volunteer';

-- 检查核心数据
SELECT COUNT(*) AS role_count FROM role;           -- 应该返回 4
SELECT COUNT(*) AS user_count FROM user;           -- 应该返回 2
SELECT COUNT(*) AS category_count FROM menu_category;  -- 应该返回 6
SELECT COUNT(*) AS content_count FROM content_item;    -- 应该返回 18
SELECT COUNT(*) AS activity_count FROM activity;       -- 应该返回 2
```

## 四、修改后端配置

编辑文件：`backend/src/main/resources/application.yml`

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/volunteer?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password: 你的MySQL密码    # ← 修改为你的密码
```

## 六、常见问题

### Q1: 提示 "Access denied for user 'root'"
检查 MySQL 密码是否正确，或者使用以下命令重置：
```sql
ALTER USER 'root'@'localhost' IDENTIFIED BY '新密码';
```

### Q2: 提示 "Unknown database 'volunteer'"
脚本会自动创建数据库，如果失败请手动创建：
```sql
CREATE DATABASE volunteer DEFAULT CHARACTER SET utf8mb4;
```

### Q3: 中文乱码
确保 MySQL 配置了 utf8mb4 字符集：
```sql
SHOW VARIABLES LIKE 'character%';
```

### Q4: 端口被占用
MySQL 默认端口 3306，如果被占用可以修改 `application.yml` 中的端口号。
