一、项目运行方式
================================================================================

1. 环境要求
-----------
   - Node.js 18.x 或更高版本
   - npm 9.x 或更高版本
   - 现代浏览器（Chrome、Firefox、Edge等）

2. 安装依赖
-----------
   打开命令行，进入 frontend 目录，执行：
   cd frontend
   npm install

3. 启动开发服务器
-----------------
   npm run dev
   
   启动后访问：http://localhost:5173

4. 构建生产版本
---------------
   npm run build
   
   构建产物位于 frontend/dist 目录

5. 后端服务
-----------
   本模块需要配合后端服务运行，后端服务地址配置在 vite.config.ts 中
   默认代理到 http://localhost:8080/api

6. 登录账号
-----------
   管理员账号：admin
   默认密码：admin123


二、需求分析
================================================================================

1. 模块概述
-----------
   系统管理模块是志愿者服务管理系统的核心管理模块，面向系统管理员用户。
   该模块提供了用户账号管理、权限分配、操作日志审计等核心功能，是整个
   系统安全运行的基础保障。

2. 用户角色
-----------
   目标用户：系统管理员
   用户特点：
   - 具有最高系统权限
   - 负责系统日常维护和管理
   - 需要监控系统运行状态
   - 需要审计用户操作行为

3. 功能需求
-----------

   3.1 用户管理功能
   ----------------
   功能描述：管理系统中所有用户账号，包括管理员、志愿者组织、志愿者、普通用户
   
   具体功能：
   (1) 用户列表展示
       - 分页显示所有用户信息
       - 支持按用户名、角色筛选
       - 显示用户基本信息（用户名、角色、邮箱、状态、创建时间）
   
   (2) 添加用户
       - 输入用户名（必填，唯一）
       - 设置初始密码（必填，最少6位）
       - 选择用户角色（管理员/志愿者组织/志愿者/普通用户）
       - 输入邮箱（选填）
   
   (3) 编辑用户
       - 修改用户角色
       - 修改邮箱
       - 启用/禁用用户账号
   
   (4) 删除用户
       - 删除指定用户账号
       - 删除前需要确认
       - 不能删除当前登录的管理员账号
   
   (5) 重置密码
       - 为用户重置密码
       - 生成新的随机密码或设置指定密码

   3.2 权限管理功能
   ----------------
   功能描述：控制不同角色用户的系统访问权限
   
   角色权限说明：
   (1) 管理员（ADMIN）
       - 拥有系统所有功能的访问权限
       - 可以管理所有用户
       - 可以查看所有操作日志
   
   (2) 志愿者组织（ORG）
       - 可以管理本组织的志愿者
       - 可以发布和管理活动
       - 可以处理求助请求
   
   (3) 志愿者（VOLUNTEER）
       - 可以查看和报名活动
       - 可以查看个人服务记录
       - 可以进行活动签到
   
   (4) 普通用户（USER）
       - 可以浏览公开内容
       - 可以发布求助请求
       - 可以申请成为志愿者

   3.3 操作日志功能
   ----------------
   功能描述：记录和审计管理员的所有操作行为
   
   具体功能：
   (1) 日志记录
       - 自动记录用户登录/登出
       - 记录用户增删改操作
       - 记录系统配置修改
       - 记录时间戳和操作者信息
   
   (2) 日志查询
       - 按时间范围查询
       - 按操作类型筛选
       - 按操作用户筛选
       - 分页展示查询结果
   
   (3) 日志导出
       - 支持导出为Excel格式
       - 可选择导出时间范围

   3.4 系统信息功能
   ----------------
   功能描述：展示系统运行状态和基本信息
   
   具体功能：
   (1) 系统状态监控
       - 显示服务器运行时间
       - 显示内存使用情况
       - 显示数据库连接状态
   
   (2) 数据备份
       - 支持手动触发数据备份
       - 下载备份文件

4. 非功能需求
-------------
   (1) 安全性
       - 所有操作需要登录验证
       - 敏感操作需要二次确认
       - 密码加密存储
   
   (2) 易用性
       - 界面简洁直观
       - 操作反馈及时
       - 支持键盘快捷操作
   
   (3) 性能
       - 页面加载时间小于2秒
       - 列表支持分页加载


三、详细设计
================================================================================

1. 系统架构设计
---------------
   本模块采用前后端分离架构：
   
   前端技术栈：
   - Vue 3 - 渐进式JavaScript框架
   - TypeScript - 类型安全的JavaScript超集
   - Element Plus - Vue 3 UI组件库
   - Pinia - Vue 3 状态管理
   - Vue Router - 路由管理
   - Axios - HTTP请求库
   - Vite - 构建工具

   后端技术栈：
   - Spring Boot 3.x
   - Spring Security - 安全框架
   - MyBatis Plus - ORM框架
   - MySQL 8.0 - 数据库

2. 数据库设计
-------------

   2.1 用户表（users）
   -------------------
   字段名          类型            说明
   ----------------------------------------------------------------
   id              BIGINT          主键，自增
   username        VARCHAR(50)     用户名，唯一
   password        VARCHAR(255)    密码（BCrypt加密）
   role            VARCHAR(20)     角色（ADMIN/ORG/VOLUNTEER/USER）
   email           VARCHAR(100)    邮箱
   enabled         TINYINT(1)      是否启用（0-禁用，1-启用）
   created_at      DATETIME        创建时间
   updated_at      DATETIME        更新时间
   
   索引：
   - PRIMARY KEY (id)
   - UNIQUE KEY uk_username (username)
   - KEY idx_role (role)

   2.2 操作日志表（operation_logs）
   --------------------------------
   字段名          类型            说明
   ----------------------------------------------------------------
   id              BIGINT          主键，自增
   user_id         BIGINT          操作用户ID
   username        VARCHAR(50)     操作用户名
   operation       VARCHAR(50)     操作类型
   method          VARCHAR(200)    请求方法
   params          TEXT            请求参数
   ip              VARCHAR(50)     操作IP地址
   status          INT             操作状态（0-失败，1-成功）
   error_msg       TEXT            错误信息
   created_at      DATETIME        操作时间
   
   索引：
   - PRIMARY KEY (id)
   - KEY idx_user_id (user_id)
   - KEY idx_created_at (created_at)
   - KEY idx_operation (operation)

3. 功能模块设计
---------------

   3.1 用户管理模块
   ----------------
   
   (1) 组件结构
       Users.vue - 用户管理主页面
       ├── 用户列表表格
       ├── 搜索筛选区域
       ├── 新增用户对话框
       ├── 编辑用户对话框
       └── 重置密码对话框
   
   (2) API接口设计
       GET    /api/users              获取用户列表（分页）
       POST   /api/users              创建新用户
       PUT    /api/users/:id          更新用户信息
       DELETE /api/users/:id          删除用户
       POST   /api/users/:id/reset-password  重置用户密码
   
   (3) 数据流程
       用户操作 -> 调用API -> 后端处理 -> 返回结果 -> 更新界面

   3.2 操作日志模块
   ----------------
   
   (1) 组件结构
       OperationLogs.vue - 操作日志主页面
       ├── 日志列表表格
       ├── 时间范围选择器
       ├── 筛选条件区域
       └── 导出按钮
   
   (2) API接口设计
       GET    /api/ops/logs           获取操作日志（分页）
       GET    /api/ops/logs/export    导出操作日志
   
   (3) 日志记录机制
       - 使用AOP切面自动记录Controller层操作
       - 记录请求参数、响应结果、执行时间
       - 异步写入数据库，不影响主业务性能

   3.3 系统信息模块
   ----------------
   
   (1) 组件结构
       System.vue - 系统信息主页面
       ├── 系统状态卡片
       ├── 服务器信息展示
       └── 数据备份区域
   
   (2) API接口设计
       GET    /api/ops/system-info    获取系统信息
       GET    /api/ops/backup         下载数据备份

4. 前端路由设计
---------------
   路径              组件              说明
   ----------------------------------------------------------------
   /login            Login.vue         登录页面
   /                 Layout.vue        主布局（需要登录）
   /dashboard        Dashboard.vue     仪表盘首页
   /users            Users.vue         用户管理
   /ops              OperationLogs.vue 操作日志
   /system           System.vue        系统信息

5. 状态管理设计
---------------
   使用Pinia管理全局状态：
   
   userStore:
   - token: string      登录令牌
   - username: string   当前用户名
   - role: string       当前用户角色
   
   方法：
   - setToken()         设置令牌
   - setUsername()      设置用户名
   - logout()           退出登录

6. 安全设计
-----------
   (1) 身份认证
       - 使用JWT令牌认证
       - 令牌存储在localStorage
       - 请求自动携带Authorization头
   
   (2) 权限控制
       - 路由守卫检查登录状态
       - 后端接口验证用户权限
       - 敏感操作记录日志
   
   (3) 数据安全
       - 密码使用BCrypt加密
       - 敏感数据传输使用HTTPS
       - SQL注入防护
