================================================================================
          志愿者服务活动中心多媒体展示系统 - 环境配置使用手册
================================================================================

================================================================================
一、环境要求
================================================================================

必需软件：
  - JDK 17 或 21（项目配置为17，兼容21）
  - Node.js 18+
  - MySQL 8.0+
  - Maven 3.8+

开发工具（任选）：
  - IntelliJ IDEA（推荐）
  - VS Code
  - Eclipse

================================================================================
二、数据库初始化（重要）
================================================================================

【步骤1】创建数据库

方式A - 使用MySQL Workbench：
    1. 打开 MySQL Workbench，连接数据库
    2. 选择 volunteer 数据库
    3. 打开文件 backend/src/main/resources/schema.sql
    4. 点击执行按钮

方式B - 使用命令行：
    mysql -u root -p volunteer < backend/src/main/resources/schema.sql

【步骤2】导入示例数据

方式A - 使用MySQL Workbench：
    1. 打开文件 backend/src/main/resources/init-data.sql
    2. 点击执行按钮

方式B - 使用命令行：
    mysql -u root -p volunteer < backend/src/main/resources/init-data.sql

【验证】执行以下SQL确认数据导入成功：
    USE volunteer;
    SELECT COUNT(*) FROM menu_category;   -- 应该返回 6
    SELECT COUNT(*) FROM content_item;    -- 应该返回 18
    SELECT COUNT(*) FROM user;            -- 应该返回 1

================================================================================
三、修改数据库连接配置
================================================================================

编辑文件：backend/src/main/resources/application.yml

找到以下内容，修改密码为你的MySQL密码：

    spring:
      datasource:
        url: jdbc:mysql://localhost:3306/volunteer?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=Asia/Shanghai
        username: root
        password: 你的MySQL密码    <-- 修改这里

================================================================================
四、后端启动
================================================================================

【使用 IntelliJ IDEA】

1. 打开 IDEA，选择 Open，打开 backend 文件夹
2. 等待 Maven 自动下载依赖（首次可能需要几分钟）
3. 如果提示 JDK 版本，选择 JDK 17 或 21
4. 找到 src/main/java/com/example/volunteer/VolunteerApplication.java
5. 右键点击，选择 Run 'VolunteerApplication'

【使用 VS Code】

1. 安装 Java 扩展包（Extension Pack for Java）
2. 打开 backend 文件夹
3. 按 F5 运行

【使用命令行】

    cd backend
    mvn clean spring-boot:run


================================================================================
五、前端启动
================================================================================

【安装依赖】

    cd frontend
    npm install

如果下载慢，先配置镜像：
    npm config set registry https://registry.npmmirror.com
    npm install

【启动开发服务器】

    npm run dev

前端地址：http://localhost:5173

================================================================================
六、访问系统（四端架构）
================================================================================

本系统采用四端架构设计：

【管理员端】系统管理
    地址：http://localhost:5173/login
    账号：admin / admin123
    功能：用户管理、权限管理、操作日志

【志愿者组织端】组织管理
    地址：http://localhost:5173/org/login
    账号：org1 / admin123
    功能：内容管理、媒体管理、活动管理、志愿者审核、求助处理

【志愿者端】志愿者服务
    地址：http://localhost:5173/portal
    账号：注册后登录
    功能：内容浏览、媒体观看、活动参与、加入组织

【普通用户端】公众服务
    地址：http://localhost:5173/user-portal
    账号：注册后登录
    功能：内容浏览、媒体观看、发布求助

角色说明：
    ADMIN     - 管理员：系统管理（用户、权限、日志）
    ORG       - 志愿者组织：内容、媒体、活动、志愿者、求助管理
    VOLUNTEER - 志愿者：浏览内容、参与活动、加入组织
    USER      - 普通用户：浏览内容、发布求助


================================================================================
七、快速体验流程
================================================================================

【流程一：管理员系统管理】访问 http://localhost:5173/login  账号：admin / admin123

1. 登录后台 → 查看仪表盘，显示用户统计和角色分布
2. 点击"用户管理" → 查看用户列表，可新增/编辑/删除用户
3. 点击"操作日志" → 查看所有管理员的操作记录
4. 点击"系统设置" → 查看系统信息/备份系统信息

--------------------------------------------------------------------------------

【流程二：组织端内容管理】访问 http://localhost:5173/org/login  账号：org1 / admin123

1. 登录组织端 → 查看工作台，显示待审核志愿者和待处理求助
2. 点击"分类管理" → 查看已有的六大分类
3. 点击"内容管理" → 点击"发布内容" → 填写标题、摘要、正文 → 上传封面图片 → 发布
4. 点击"媒体资源" → 点击"上传资源" → 选择一张图片或视频上传
5. 点击"播放列表" → 新建列表 → 选择刚上传的媒体资源或者内容资源，支持混排

【流程三：组织端活动管理】

6. 点击"活动列表" → 点击"发布活动" → 填写活动名称、时间、地点、人数上限 → 确定
7. 系统自动生成签到码，记下这个签到码（如：382388）
8. 有志愿者报名后 → 点击"报名名单" → 可查看报名信息 → 可点击"导出名单"
9. 点击"签到统计" → 查看签到率报表

【流程四：组织端志愿者和求助管理】

10. 点击"志愿者审核" → 查看待审核的志愿者申请 → 点击"通过"或"拒绝"
11. 点击"求助处理" → 查看待处理的求助 → 点击"处理" → 填写回复内容 → 完成

【流程五：组织端终端发布】

12. 点击"布局模板" → 查看已有布局（单屏、左右分屏、上下分屏）
13. 点击"终端管理" → 查看终端列表和在线状态 → "绑定"按钮可绑定播放列表
14. 点击"广播推送" → 创建插播任务，插播优先显示

--------------------------------------------------------------------------------

【流程五：志愿者浏览内容】访问 http://localhost:5173/portal

1. 打开志愿者首页 → 查看不同分类下（文明XX、志愿者APP等）的内容
2. 点击任意内容卡片 → 查看内容详情
3. 点击"媒体展示" → 切换"图片"/"视频"筛选 → 点击查看或播放

【流程六：志愿者注册并报名活动】

4. 点击右上角"登录" → 选择"注册" → 填写姓名、手机号 → 完成注册
5. 登录后 → 查看活动列表
6. 点击感兴趣的活动 → 点击"报名参加" → 报名成功
7. 点击右上角消息图标 → 查看"报名成功"的站内通知

【流程七：志愿者签到打卡】

8. 活动当天 → 收到签到提醒通知
9. 点击"签到"按钮 → 输入管理员提供的签到码（如：382388） → 完成签到

--------------------------------------------------------------------------------

【流程八：普通用户发布求助】访问 http://localhost:5173/user-portal

1. 打开用户门户 → 浏览内容和媒体
2. 点击"注册" → 填写用户名、密码 → 完成注册
3. 登录后 → 点击"发布求助" → 选择组织 → 填写求助内容 → 提交
4. 查看"我的求助记录" → 等待组织回复

================================================================================
十、常见问题解决
================================================================================

【问题1】Maven 下载依赖很慢

解决：配置阿里云镜像
在用户目录下创建或编辑 .m2/settings.xml：

    <settings>
      <mirrors>
        <mirror>
          <id>aliyun</id>
          <mirrorOf>central</mirrorOf>
          <url>https://maven.aliyun.com/repository/central</url>
        </mirror>
      </mirrors>
    </settings>

【问题2】IDEA 提示 JDK 版本不对

解决：
    File -> Project Structure -> Project SDK -> 选择 JDK 17 或 21
    File -> Settings -> Build -> Compiler -> Java Compiler -> Target bytecode version -> 17

【问题3】端口被占用

后端 8080 端口：修改 application.yml 中的 server.port
前端 5173 端口：修改 vite.config.ts 中的 server.port

【问题4】数据库连接失败

检查：
    1. MySQL 服务是否启动
    2. 用户名密码是否正确
    3. 数据库 volunteer 是否已创建

【问题5】前端编译报错

解决：删除 node_modules 重新安装
    Windows: rmdir /s /q node_modules
    然后: npm install

【问题6】登录后台提示"用户名或密码错误"

检查：
    1. 确认已执行 init-data.sql 导入管理员账号
    2. 默认账号：admin  密码：admin123
