================================================================================
一、环境要求
================================================================================

必需软件：
  - JDK 17 或 21（项目配置为17，兼容21）
  - Node.js 18+
  - MySQL 8.0+
  - Maven 3.8+

开发工具（任选）：
  - IntelliJ IDEA（推荐）
  - VS Code
  - Eclipse

验证环境：
    java -version      # 应显示 17 或 21
    node -v            # 应显示 18.x 或更高
    npm -v             # 应显示 9.x 或更高
    mysql --version    # 应显示 8.x

================================================================================
二、数据库初始化（重要 - 新成员必做）
================================================================================

【方式一】命令行执行（推荐）

    mysql -u root -p < backend/src/main/resources/volunteer_complete.sql

或者进入resources目录后执行：
    cd backend/src/main/resources
    mysql -u root -p < volunteer_complete.sql

【方式二】使用 MySQL Workbench / Navicat

    1. 打开数据库管理工具，连接到 MySQL
    2. 打开文件：backend/src/main/resources/volunteer_complete.sql
    3. 点击执行按钮
    4. 等待执行完成

【验证数据库】执行以下 SQL 确认数据导入成功：

    USE volunteer;
    SELECT COUNT(*) FROM role;            -- 应该返回 4
    SELECT COUNT(*) FROM user;            -- 应该返回 29
    SELECT COUNT(*) FROM volunteer_org;   -- 应该返回 6
    SELECT COUNT(*) FROM volunteer;       -- 应该返回 16
    SELECT COUNT(*) FROM terminal;        -- 应该返回 6
    SELECT COUNT(*) FROM menu_category;   -- 应该返回 6
    SELECT COUNT(*) FROM content_item;    -- 应该返回 36
    SELECT COUNT(*) FROM activity;        -- 应该返回 12（含2个仅限成员活动）
    SELECT COUNT(*) FROM playlist;        -- 应该返回 6
    SELECT COUNT(*) FROM layout_template; -- 应该返回 6
    SELECT COUNT(*) FROM help_request;    -- 应该返回 8
    SELECT COUNT(*) FROM volunteer_message; -- 应该返回 34

================================================================================
三、修改数据库连接配置
================================================================================

编辑文件：backend/src/main/resources/application.yml

找到以下内容，修改密码为你的 MySQL 密码：

    spring:
      datasource:
        url: jdbc:mysql://localhost:3306/volunteer?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=Asia/Shanghai
        username: root
        password: 你的MySQL密码    <-- 修改这里

================================================================================
四、后端启动
================================================================================

【使用 IntelliJ IDEA】

1. 打开 IDEA，选择 Open，打开 backend 文件夹
2. 等待 Maven 自动下载依赖（首次可能需要几分钟）
3. 如果提示 JDK 版本，选择 JDK 17 或 21
4. 找到 src/main/java/com/example/volunteer/VolunteerApplication.java
5. 右键点击，选择 Run 'VolunteerApplication'

【使用 VS Code】

1. 安装 Java 扩展包（Extension Pack for Java）
2. 打开 backend 文件夹
3. 按 F5 运行

【使用命令行】

    cd backend
    mvn clean spring-boot:run

后端启动成功后，访问 http://localhost:8080 应该返回 JSON 数据

================================================================================
五、前端启动
================================================================================

【安装依赖】

    cd frontend
    npm install

如果下载慢，先配置镜像：
    npm config set registry https://registry.npmmirror.com
    npm install

【启动开发服务器】

    npm run dev

前端地址：http://localhost:5173

================================================================================
七、快速体验流程（重要）
================================================================================

以下流程帮助你快速了解系统的完整功能，建议按顺序体验。

--------------------------------------------------------------------------------
【流程一】管理员端 - 系统管理
--------------------------------------------------------------------------------
访问地址：http://localhost:5173/login
测试账号：admin / admin123

步骤1：登录系统
    → 输入账号密码 → 点击登录 → 进入管理后台

步骤2：查看仪表盘
    → 首页显示系统概览
    → 查看用户总数
    → 查看最近操作记录

步骤3：用户管理
    → 点击左侧菜单"用户管理"
    → 查看用户列表（admin、org1 等）
    → 点击"新增用户" → 填写用户名、密码、角色 → 保存
    → 可编辑、删除、启用/禁用用户

步骤4：操作日志
    → 点击左侧菜单"操作日志"
    → 查看所有管理员的操作记录
    → 支持按时间、用户名筛选

步骤5：系统设置
    → 点击左侧菜单"系统设置"
    → 查看系统信息（版本、运行时间等）
    → 可进行系统备份操作

--------------------------------------------------------------------------------
【流程二】组织端 - 内容管理
--------------------------------------------------------------------------------
访问地址：http://localhost:5173/org/login
测试账号：org1 / admin123

步骤1：登录组织端
    → 输入账号密码 → 点击登录 → 进入组织工作台

步骤2：查看工作台
    → 待审核志愿者数量
    → 待处理求助数量

步骤3：分类管理
    → 点击左侧菜单"分类管理"
    → 查看已有的六大分类：文明XX、志愿者APP、志愿者网、雷锋热线、公益活动、公益广告
    → 可新增、编辑、删除分类

步骤4：内容管理
    → 点击左侧菜单"内容管理"
    → 查看已有的36条示例内容（每个分类6条）
    → 点击"发布内容" → 选择分类 → 填写标题、摘要、正文
    → 上传封面图片（支持拖拽上传）
    → 点击"发布" → 内容上线

步骤5：媒体资源
    → 点击左侧菜单"媒体资源"
    → 点击"上传资源" → 选择图片或视频文件
    → 支持批量上传
    → 上传后可预览、删除

步骤6：播放列表
    → 点击左侧菜单"播放列表"
    → 点击"新建列表" → 输入列表名称
    → 添加媒体资源或内容到列表
    → 支持拖拽排序
    → 设置每项显示时长

--------------------------------------------------------------------------------
【流程三】组织端 - 活动管理
--------------------------------------------------------------------------------
继续使用组织端账号：org1 / admin123

步骤7：发布活动
    → 点击左侧菜单"活动列表"
    → 点击"发布活动"
    → 填写活动信息：
        - 活动名称：如"社区环保志愿行动"
        - 活动描述：详细说明活动内容
        - 活动地点：如"XX社区广场"
        - 开始时间：选择日期时间
        - 结束时间：选择日期时间
        - 人数上限：如 30 人
        - 仅限成员：勾选后只有组织成员可报名（新功能）
    → 点击"确定" → 系统自动生成签到码
    → 记下签到码（如：382388），活动当天志愿者签到需要
    
    【新功能说明】活动现已关联组织：
    - 每个活动都属于发布它的组织
    - 可设置"仅限成员"，只有加入该组织的志愿者才能报名
    - 公开活动所有志愿者都可以报名

步骤8：查看报名
    → 有志愿者报名后，点击活动的"报名名单"
    → 查看已报名志愿者列表
    → 可点击"导出名单"下载 Excel

步骤9：签到统计
    → 点击左侧菜单"签到统计"
    → 查看各活动的签到率
    → 查看签到时间分布图表

--------------------------------------------------------------------------------
【流程四】组织端 - 志愿者和求助管理
--------------------------------------------------------------------------------
继续使用组织端账号：org1 / admin123

步骤10：志愿者审核
    → 点击左侧菜单"志愿者审核"
    → 查看待审核的志愿者申请列表
    → 点击"查看详情" → 查看志愿者信息
    → 点击"通过" → 志愿者加入组织
    → 或点击"拒绝" → 填写拒绝原因

步骤11：求助处理
    → 点击左侧菜单"求助处理"
    → 查看待处理的求助列表
    → 点击"处理" → 查看求助详情
    → 填写回复内容 → 点击"完成处理"
    → 用户会收到处理结果通知

--------------------------------------------------------------------------------
【流程五】组织端 - 终端发布
--------------------------------------------------------------------------------
继续使用组织端账号：org1 / admin123

步骤12：布局模板
    → 点击左侧菜单"布局模板"
    → 查看已有布局：
        - 单屏全屏：1个分区，100%显示
        - 左右分屏：2个分区，左右各50%
        - 上下分屏：2个分区，上下各50%
        - 三分屏：3个分区，左侧50%+右侧上下各25%
        - 四宫格：4个分区，四等分
        - 左一右二：3个分区，左侧60%+右侧上下各20%
    → 可新建自定义布局

步骤13：终端管理
    → 点击左侧菜单"终端管理"
    → 查看终端列表和在线状态
    → 点击"绑定" → 选择播放列表 → 绑定到终端
    → 终端会自动播放绑定的内容

步骤14：广播推送
    → 点击左侧菜单"广播推送"
    → 点击"创建插播"
    → 选择媒体资源或内容
    → 选择目标终端或终端组
    → 设置播放时间
    → 插播内容会优先显示

【流程七】志愿者端 - 注册并报名活动

    - Vue 3                   - 前端框架

    - Element Plus            - UI组件库

    - Pinia                   - 状态管理
    - Vue Router              - 路由管理

十、常见问题解决
================================================================================

【问题1】Maven 下载依赖很慢

解决：配置阿里云镜像
在用户目录下创建或编辑 .m2/settings.xml：

    <settings>
      <mirrors>
        <mirror>
          <id>aliyun</id>
          <mirrorOf>central</mirrorOf>
          <url>https://maven.aliyun.com/repository/central</url>
        </mirror>
      </mirrors>
    </settings>

--------------------------------------------------------------------------------

【问题2】IDEA 提示 JDK 版本不对

解决：
    File -> Project Structure -> Project SDK -> 选择 JDK 17 或 21
    File -> Settings -> Build -> Compiler -> Java Compiler -> Target bytecode version -> 17

--------------------------------------------------------------------------------

【问题3】端口被占用

后端 8080 端口：修改 application.yml 中的 server.port
前端 5173 端口：修改 vite.config.ts 中的 server.port

查看端口占用：
    Windows: netstat -ano | findstr :8080
    杀死进程: taskkill /PID <进程ID> /F

--------------------------------------------------------------------------------

【问题4】数据库连接失败

检查：
    1. MySQL 服务是否启动
       Windows: services.msc 查看 MySQL 服务状态
    2. 用户名密码是否正确
    3. 数据库 volunteer 是否已创建
    4. application.yml 中的密码是否正确

--------------------------------------------------------------------------------

【问题5】前端编译报错

解决：删除 node_modules 重新安装
    Windows: rmdir /s /q node_modules
    然后: npm install

如果还是报错，尝试清除缓存：
    npm cache clean --force
    npm install

--------------------------------------------------------------------------------

【问题6】登录后台提示"用户名或密码错误"

检查：
    1. 确认已执行 volunteer_complete.sql 导入数据
    2. 管理员账号：admin / admin123
    3. 组织端账号：org1、org2、org3、org4、org5、org6 / admin123
    4. 志愿者账号：13800001111~13800016666 / admin123（手机号登录）
    5. 用户端账号：user1~user6 / admin123

--------------------------------------------------------------------------------

【问题7】上传文件失败

检查：
    1. backend/uploads 目录是否存在
    2. 目录是否有写入权限
    3. 文件大小是否超过限制（默认10MB）

--------------------------------------------------------------------------------

【问题8】npm install 报错 EACCES 权限问题

解决（Windows）：
    以管理员身份运行命令提示符
    或者修改 npm 全局目录权限
