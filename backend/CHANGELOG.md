# Changelog

## 2025-12-24
- Media 删除时同时尝试删除 `uploads/` 下的物理文件。
- 播放列表新增条目查询接口、更新/删除时清理绑定；终端新增已绑定播放列表查询。
- CORS + 静态资源映射 `uploads/`；新增文件上传接口及前端管理页面。
- 新增终端心跳表，记录心跳日志并提供查询接口。
- 新增布局管理接口、播放列表关联布局；媒体下载接口。
- 新增插播（广播）接口，终端可查询活跃插播；前端增加布局、插播管理页面。
- 新增操作日志表与拦截器，admin 接口查看 `/api/ops/logs`；新增用户管理（用户/角色 CRUD），前端增加用户管理与操作日志页面。  
- 新增系统信息/备份导出接口（admin）、前端系统管理页；终端超时自动标记离线；新增前端系统管理页入口。
- 新增公共展示接口（分类/内容、终端播放拉取），前端增加内容展示与终端预览页面；初始化六大菜单分类种子；终端超时标记离线；媒体下载、公用接口放开权限。
- 新增志愿者/活动模块：表与实体；后台活动管理、报名列表；公共接口支持志愿者注册与活动报名；前端活动管理、志愿者注册、活动报名页面。
- 增量：媒体缩略图字段；活动签到码/签到日志/统计接口、公共签到；终端属性编辑、播放列表分组发布；仪表盘统计卡；活动页面支持签到码复制与统计；新增终端心跳超时标记离线配置化。
- 增量（管理端收尾）：播放列表封面与预览接口；媒体封面上传；终端分组发布接口与在线/离线看板；活动签到二维码与前台签到页，报名/签到进度可视化；播放列表预览弹窗与封面展示。
- 用户端首版：公共内容详情接口；播放拉取返回媒体资源；志愿者报名查询接口；新增用户门户页（内容六大菜单、视频播放、活动报名、志愿者注册/我的报名）。
- 用户端优化：门户新增自动轮播/上一条/下一条、播放列表切换与终端码记忆；内容加载骨架与空态；活动报名后自动关联“我的报名”；签到页增加返回门户；登录/后台增加门户入口。
- 用户端视觉/播放增强：内容卡片与详情增加大图、标签、面包屑；视频区卡片展示封面/时长；播放器新增倍速、静音/音量调节；终端选择支持下拉收藏与快速切换。
- 用户端大更新：内容头条/推荐标记支持；头条/列表视觉与标签色彩优化；播放区收藏批量管理、进度条缓冲/缩略预览；多终端预览显示播放中媒体摘要与轮询刷新。
- 用户端深度优化：头条优先推荐标记、视频卡画质标记（HD/SD）、进度条缩略预览、收藏批量管理置顶、播放中媒体实时刷新。
