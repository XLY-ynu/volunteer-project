# Volunteer Media Platform Frontend

## 开发
```bash
npm install
npm run dev
```
默认代理 `/api` 到 `http://localhost:8080`。

## 目录
- `src/views/Login.vue` 登录页
- `src/views/Dashboard.vue` 仪表盘占位
- 资源管理：`src/views/Media.vue`
- 分类管理：`src/views/Categories.vue`
- 内容管理：`src/views/Content.vue`
- 播放列表：`src/views/Playlists.vue`
- 终端管理：`src/views/Terminals.vue`
- 布局管理：`src/views/Layouts.vue`
- 插播管理：`src/views/Broadcasts.vue`
- 操作日志：`src/views/OperationLogs.vue`
- 用户管理：`src/views/Users.vue`
- 系统管理：`src/views/System.vue`
- 内容展示：`src/views/PublicContent.vue`
- 终端预览：`src/views/TerminalPreview.vue`
- 活动管理：`src/views/Activities.vue`
- 志愿者注册：`src/views/VolunteerPublic.vue`
